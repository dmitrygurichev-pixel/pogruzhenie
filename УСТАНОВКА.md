# Мессенджер «Полное погружение»: установка

Своё веб-приложение для группы: общий чат, личка с преподавателем, памятки и домашки по расписанию, таблица «кто что сдал». Ставится на телефон с сайта, без App Store и Google Play.

## Что понадобится

- **Сервер (VPS) с Ubuntu 22.04 или 24.04.** Хватит самого простого тарифа: 1 ядро, 1 ГБ памяти. Подойдёт любой российский хостинг.
- **Домен или поддомен**, например `chat.28school.ru`. Можно попросить у школы поддомен.
- Минут 20.

## Установка

1. **Направьте домен на сервер.** В панели, где управляете доменом, создайте A-запись: имя — поддомен (например `chat`), значение — IP-адрес сервера. Подождите 10–30 минут.
2. **Загрузите архив на сервер** (с компьютера, в терминале):
   ```
   scp pogruzhenie.zip root@IP-СЕРВЕРА:
   ssh root@IP-СЕРВЕРА
   ```
3. **Запустите установку:**
   ```
   apt-get install -y unzip && unzip pogruzhenie.zip && cd pogruzhenie
   bash install.sh chat.28school.ru
   ```
   Скрипт сам скачает сервер PocketBase, создаст базу, спросит логин для панели администратора и запустит приложение. HTTPS-сертификат подключится автоматически.
4. **Сразу зарегистрируйтесь сами.** Откройте `https://ваш-домен` и нажмите «Регистрация». Первый зарегистрированный становится преподавателем, все следующие — только по ссылке-приглашению.

## Как пользоваться

- **Пригласить группу:** «Ученики» → «Пригласить» → «Скопировать ссылку», и отправьте её ученикам в любой мессенджер. Если ссылка ушла не туда, создайте новую: старая перестанет работать.
- **Занятие 1 уже заполнено:** памятка и домашка откроются ученикам 5 октября в 21:00 по Москве, сдать до 7 октября, 19:00. Поправить можно через «Занятия» → занятие → «Редактировать».
- **Новое занятие:** «Занятия» → «Новое занятие». Укажите время открытия: в эту минуту в общий чат придёт анонс, а у учеников при входе автоматически откроется памятка. К памятке можно приложить PDF.
- **Проверка домашек:** «Ученики» — таблица по всем занятиям. Нажмите на кружок ученика, посмотрите работу, затем «Принять работу» или «Вернуть на доработку». Ученику автоматически придёт личное сообщение.
- **Установка на телефон (покажите на первом занятии):** iPhone — в Safari «Поделиться» → «На экран „Домой“». Android — в Chrome меню ⋮ → «Добавить на главный экран».

## Панель администратора

`https://ваш-домен/_/` — для служебных задач:

- **Резервные копии:** Settings → Backups, включите автоматические раз в сутки.
- **Восстановление пароля по почте:** Settings → Mail settings, данные SMTP вашей почты. Пока почта не настроена, забытый пароль меняется здесь: Collections → users.
- **Удалить ученика или поменять роль:** Collections → users.

## Обслуживание

- Перезапуск: `systemctl restart pogruzhenie`
- Журнал ошибок: `journalctl -u pogruzhenie -n 100`
- Все данные (сообщения, фото, работы) лежат в `/opt/pogruzhenie/pb_data` — эту папку и нужно сохранять.
- Обновление интерфейса: замените папку `/opt/pogruzhenie/pb_public` и перезапустите службу.

## Чего пока нет

- **Пуш-уведомлений.** О новых сообщениях сообщает точка на вкладке «Чат». Можно добавить следующим шагом.
- **Видео в чате:** только фото. Видео можно отправлять ссылкой.
